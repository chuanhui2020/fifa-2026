# FIFA 2026 世界杯赛程

团队内部使用的 FIFA 2026 世界杯赛程网站，PolyMarket 风格深色 UI，支持移动端和微信内置浏览器。

## 功能

- 104 场完整赛程（小组赛 + 淘汰赛）
- 按阶段 / 小组筛选
- 按日期分组展示
- 比赛状态实时标识（即将开始 / 进行中 / 已结束）
- 响应式布局，微信端适配
- 深色主题，高对比度，护眼

## 技术栈

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Cloudflare Pages

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:3000 查看。

## 部署

目标平台：Cloudflare Pages（配置中）
